# 11: 跨平台三 peer 验收与部署说明

**What to build:** 用户能够按说明在已支持的平台部署同一版本，以三个 peer 验证广播和双向文本同步，并清楚知道配置、依赖、升级方式、失败行为及尚未验证的限制。

**Blocked by:** 07 — WSL 与 Windows 剪切板桥接；08 — Xorg 双向同步；09 — KDE Wayland 双向同步与能力提示；10 — macOS 远程桌面回流验收。

**Status:** ready-for-human

**Execution:** 部分验收。已提供部署说明、官方 ntfy 三订阅者测试、真实跨平台三 peer 和 Windows 原生双向证据；实际 Xorg、GNOME 及完整远程桌面矩阵未通过，不宣称发布验收完成。见[验证记录](../../../docs/clipboard-sync-validation.md)。

这是所有增量合并后的集成验收，不增加新功能。通过依赖链覆盖 Windows、macOS 和共享发布/写入重试；不要求穷举平台笛卡尔积，但每个承诺支持的平台都必须有实际验证证据。

- [ ] 使用可控的官方 ntfy 实例，记录实际二进制版本、消息上限、权限及相关限流配置；以合成文本验证三个独立订阅者接收同一内容，而非竞争消费。
- [ ] 至少一个三 peer 组合跨两类平台；无重试及远程桌面介入时，A 复制一次，B/C 均得到同步文本，A 自身回送零写入，经过多个监听周期发布次数仍为 1。轮换发起端验证双向行为。
- [ ] 真实验证矩阵覆盖 macOS、Windows、WSL、Xorg、受支持 KDE Wayland；GNOME 和无协议环境验证能力报告及当前可用的仅接收路径。交叉编译或 fake 测试不能替代桌面运行。
- [ ] 将共享失败恢复与各平台合并验证：发布限流/超时/响应未知、内存 FIFO 边界、写入暂时占用和超时、新本地状态取代旧待写任务；不得因平台接入而另设不一致的重试规则。
- [ ] 验证默认仅接收、显式双向、启动只建立基线、网络重连保留 origin/队列和进程重启不恢复；确认没有服务器历史重放。
- [ ] 验证空字符串、中文、emoji、首部和中间空白、全部尾部 CR/LF 去除，以及序列化字节数边界；超限、附件和坏协议显式报告，不截断或粘贴附件说明。
- [ ] 验证新版协议和普通 ntfy 文本兼容；明确所有 peer 需要一起升级，旧版二进制不能透明接收新版封装。
- [ ] 部署说明覆盖模式和全部新增配置默认值、服务器大小限制匹配、TOKEN 读写权限、各平台组件/桌面会话要求、WSL helper，以及明确的失败和能力提示。
- [ ] 日志和故障输出不泄露正文、完整 hash、TOKEN 或完整认证请求；队列正文不落盘，未送达内容不伪报成功。
- [ ] 文档准确记录 GNOME 不自动上传、来源过滤尚未启用、图片不支持，以及远程桌面延迟旧值、偶发重复通知、漏掉瞬时状态和非全局最终一致的边界。
- [ ] 运行受影响目标的格式、构建/类型检查、lint、测试及跨模块集成测试，汇总各平台真实 smoke test 和远程桌面证据。缺环境或失败项列为未验证/未通过，不宣称发布验收完成。
